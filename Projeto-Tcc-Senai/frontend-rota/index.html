    Onde você está?

    Como usar

    1. Diga onde você está. Escaneie o QR Code do bloco ou toque no cartão “Você está em”.
    2. Escolha o destino. Use a busca, a lista ou toque num bloco no mapa.
    3. Siga a linha azul. Os passos mostram o caminho e a distância de cada trecho.
    4. Rota acessível evita trechos com escada.
    5. Errou o destino? Toque em “Trocar destino” ou use o botão voltar do celular.
